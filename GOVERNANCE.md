# EnginEx Governance

EnginEx is developed and maintained through Golden Obsidian LLC. The project is currently maintainer-led; this document describes the current arrangement rather than claiming community governance, independent certification, or a separate legal entity.

## Stewardship and decisions

The project steward is responsible for repository administration, contribution acceptance, merges, releases, project communications, security coordination, and use of project names and branding. Participation in issues, discussions, or pull requests does not itself grant repository permissions or maintainer status.

Use GitHub Discussions for questions and design exploration, and Issues for reproducible defects, focused improvements, and tracked work. For changes affecting APIs, the expression grammar, compiler, security boundaries, compatibility, or licensing, discuss the proposal before substantial implementation when practical. The maintainer makes the final repository decision; community feedback informs but does not bind it. There is no guaranteed response time.

## Contribution review

Contributions should have a clear purpose, preserve license and third-party notices, include tests, document compatibility and security impacts, and state exact validation commands. Maintainers may request changes or decline contributions that create unacceptable security or maintenance risks. Only maintainers with repository permissions can merge.

A passing CI run is evidence for the checks actually performed, not an independent audit or production certification.

## Maintainers and access

Maintainer invitations may consider technical judgment, sustained constructive participation, security awareness, communication, availability, and conflicts of interest. There is no automatic path from contribution to maintainership. Grant repository access deliberately and with least privilege.

## Security and community

Follow SECURITY.md and THREAT_MODEL.md for vulnerability disclosure. Do not publish exploitable details, credentials, private data, or production secrets publicly. Community participation is governed by CODE_OF_CONDUCT.md. The project currently has no separate moderation committee, incident-response team, or funded support group.

## Funding and conflicts

EnginEx is currently unfunded. No public donation, sponsorship, grant, or contributor-compensation program is established. Funding does not grant ownership, repository administration, maintainer status, intellectual-property rights, roadmap control, or endorsement. Disclose material conflicts that could affect technical or project decisions.

## Licensing and policy changes

Current original EnginEx materials controlled by the project maintainers are distributed under GPL-2.0-or-later unless a file or component carries a different notice. Earlier MIT grants for previously published copies are not withdrawn. Third-party material retains its applicable terms. See LICENSE, COPYRIGHT, NOTICE.md, and TRADEMARKS.md.

Material governance changes should be discussed openly where practical and made through a pull request. The policy in the default branch is the current reference.
