# Third-Party Notices

EnginEx core has no mandatory third-party runtime dependencies. Its optional peer integrations include the Model Context Protocol server package and Zod; those integrations are not installed or loaded by the core renderer by default.

Consumers that install optional peer packages must review the exact versions in their lockfile and follow each package's license and notice requirements. Preserve all file-specific notices for bundled or third-party material.

The current original EnginEx project materials controlled by Golden Obsidian LLC use GPL-2.0-or-later. Earlier copies published under MIT remain subject to the permissions already granted for those copies. See LICENSE, COPYRIGHT, and NOTICE.md.

Before distribution, review the resolved dependency graph, generate an SBOM, and run dependency and license scans.
